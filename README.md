# Complex littoral habitats enhance freshwater crayfish populations

This repository contains the full reproducible workflow supporting the manuscript:

**“Complex littoral habitats enhance freshwater crayfish populations in five volcanic lakes of Aotearoa New Zealand.”**

The repository includes all code used for data processing, statistical analyses, and figure generation, as well as derived datasets used in the analyses. Raw field data are archived separately in an open-access data repository with a DOI (see below).

### Raw data
Raw field data are archived in an open-access repository and are provided **unchanged** to preserve data provenance.

The primary raw dataset is:
- `Natural_habitat.xlsx`  
  An Excel workbook containing original field observations across multiple worksheets, including site information, environmental variables, fish and kōura catch data, macrophytes, and macroinvertebrates.

### Derived data
Derived datasets used for statistical modelling and figure generation are created programmatically by the analysis pipeline and saved to:

- `data/derived/Monitoring_CPUE_data.csv`
- `data/derived/habitat_classification.csv`

These files can be regenerated at any time by running the Quarto document.

## Code availability

All analyses were conducted in **R** and implemented in a single reproducible **Quarto** document:

- `index.qmd`

This document:
- Loads raw data
- Performs data filtering and transformation
- Calculates CPUE and BPUE metrics
- Fits statistical models
- Generates all figures used in the manuscript

The code is fully self-contained and relies only on publicly available R packages.
